# Syntecxhub Data Science Internship - Week 4 Task

## Project 1: Sales Analysis

### Project Overview
This repository contains the completed project for **Project 1: Sales Analysis** under **Week 4** of the Syntecxhub Data Science Internship program[cite: 9].

---

### Tasks Completed
1. **Dataset Generation & Loading:** Simulated a comprehensive retail sales dataset encompassing transaction dates, product categories, regions, quantities, and unit prices.
2. **KPI Computation:** Calculated core business metrics including **Total Revenue**, **Average Order Value (AOV)**, **Top Regions**, and **Top Products**.
3. **Trend & Seasonality Visualization:** Generated visual charts highlighting monthly sales trends (seasonality), top-performing products, regional revenue distribution, and order value boxplots.
4. **Visualization & Report Export:** Exported all combined analytical charts into a high-resolution image report (`sales_analysis_report.png`).

---

### Key Insights & Recommendations
* **Top Revenue Drivers:** Laptops and high-end electronics generate the highest total revenue share, serving as core growth drivers for the retail line.
* **Seasonality Patterns:** Sales peak during specific seasonal periods, indicating prime windows for targeted marketing and promotional campaigns.
* **Regional Strength:** The 'West' and 'North' regions demonstrate robust purchasing volume, making them ideal zones for expanded inventory allocation.
* **Business Strategy Recommendation:** Focus promotional discounts and bundle offers on mid-tier products to boost Average Order Value (AOV) across lagging regional markets.
